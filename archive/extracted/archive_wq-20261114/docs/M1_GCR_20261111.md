# GCR（Gradient-Calibrated RankUp）结果：NO-GO

## 1. 假设

RankUp ARC 的失败不是“排序信息无用”，而是排序梯度相对回归尺度失控。把 ARC 对共享参数的梯度范数逐步限制为 L1 梯度的 ρ=0.10，应能保留 Pearson 收益且不破坏 MAE。

## 2. Fold0 base 结果（Student Raw，100 条折外）

按预注册 P1/P2，c1 在 base 阶段即明确失败；未运行 96 步读出，未运行 c2 无标签消融，未做任何参数救援。

## 3. 机制观察

- 校准器按设计工作：λ_t 在 0.009–0.497 之间，按 `0.10 × ||g_reg|| / ||g_arc||` 逐步更新；
- g_reg 从 4.41 衰减到 0.89，g_arc 稳定在 2.2 左右，说明排序梯度确实不随回归收敛；
- 即使把排序梯度压到回归的 10%，编码器仍在 1600 步内漂移到 pair-classification 解：折外预测 SD 扩张到 2.29×，R² 深度为负，训练 L1 却降到 0.0064（典型“拟合训练标签、破坏表示几何”）；
- 这与 B3（固定权重 0.2，MAE 0.339）和 B4（仅有标签 ARC，0.157）的旧证据一致：**主要破坏源是无标签 ARC 项，且问题不只是梯度幅值，而是梯度方向与连续 VAD 回归不兼容**。

## 4. 对照口径说明（必须披露）

- c0 与 c1 由同一脚本、同一进程配方、同一 seed/数据顺序训练，二者是合法配对；
- 但 c0 的 0.158945 比历史 B2（0.15116/0.15186）高 0.0078。单步前向/反向与模型初始化已逐项对齐（同一 loss、同一参数和），差异来自 1600 步训练中的数值路径/host 级非确定性；
- 因此本轮**不能**把 c0 当作 B2 的绝对复现值，只能用 c1 vs c0 的配对差判断候选；该差值（+0.21 MAE）远大于任何已记录的复现噪声（≤0.0015），NO-GO 结论不受影响。

## 5. 判定

`GCR = NO-GO`。

- 梯度预算校准不能挽救 RankUp ARC；
- “排序信息有用、只是梯度没对齐”这一假设被本轮直接反驳：对齐到 10% 后仍然崩溃；
- 不再沿 ARC/排序家族做权重、温度、置信阈值或 λ_max 的扫描；
- 若继续组件一，必须换一个**不向编码器回传全局排序/伪标签梯度**的信息利用方式，或重新界定 M1 的组件一口径。
